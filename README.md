# sensors-tray
Dodatek do GNOME, sensor temperatury i pozostalych elementów

## Dane Środowiska
- **OS:** Debian GNU/Linux 13 (trixie) x86_64
- **Sprzęt:** ThinkPad T15 Gen 2i
- **Środowisko (DE):** GNOME 48.7 (Wayland)
- **Dodatki:** Dash to Panel

## Identyfikator Rozszerzenia (UUID)
Wybrany identyfikator to: **`sensors-tray@pavart`**
Ścieżka do katalogu rozszerzenia: `~/.local/share/gnome-shell/extensions/sensors-tray@pavart`

Po dodaniu plików w lokalizacji wskazanej powyżej należy przelogować sesję Waylanda.

Następnie, w terminalu wpisać:

```bash
gnome-extensions enable sensors-tray@pavart
```

Wtyczka uruchomi się w prawym, dolnym rogu ekranu.
